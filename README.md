# Loan Application Platform

A comprehensive platform for managing loan applications, connecting borrowers with lenders, and streamlining the loan process.

## Features

### Loan Application Features
- Complete loan application form based on standard URLA (Uniform Residential Loan Application)
- Document upload and management
- Communication between borrowers and lenders
- Loan status tracking
- Download loan data in MISMO 3.4 XML format for compliance and data exchange

### Borrower Features
- Apply for loans
- Track application status
- Upload required documents
- Communicate with lenders
- View loan details and milestones

### Lender Features
- Review loan applications
- Request additional documents
- Approve or reject loan applications
- Set up milestones for loan processing
- Generate pre-approval letters
- Download loan data in MISMO 3.4 XML format for integration with other systems

## Getting Started

### Prerequisites
- Node.js (v14+)
- MongoDB
- npm or yarn

### Installation
1. Clone the repository
2. Install dependencies in both frontend and backend:
```bash
cd frontend && npm install
cd ../backend && npm install
```
3. Set up environment variables
4. Start the development servers:
```bash
# Backend
cd backend && npm run dev

# Frontend
cd frontend && npm run dev
```
